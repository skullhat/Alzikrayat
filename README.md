# Alzikrayat Project | Memories

Alzikrayat is a simple photo-sharing website where members can upload photos, share the stories behind them, and interact through comments.

This project was developed for Course Project 1 in the **Advanced Web Technologies** course at **Sudan University of Science and Technology**.

The application was built from scratch using a custom MVC structure without Laravel, Symfony, or other backend frameworks.

## Features

- User registration, login, and logout.
- Password hashing using Bcrypt.
- Photo uploads with support for JPG, PNG, and WebP.
- Maximum upload size of 5 MB.
- Photo titles and personal stories.
- Multiple gallery layouts, including grid, list, and slideshow views.
- Comments without page reloads using JavaScript.
- Friend tagging in photos.
- Protection against SQL injection, XSS, and CSRF attacks.
- Validation on the HTML, JavaScript, and PHP levels.
- Responsive design for mobile, tablet, and desktop screens.

## Technologies

- **Backend:** PHP
- **Database:** MySQL with PDO
- **Frontend:** HTML5, Bootstrap 5.3, JavaScript, and custom CSS

Bootstrap and Font Awesome are loaded online, so an internet connection may be required for some styles and icons to appear correctly.
